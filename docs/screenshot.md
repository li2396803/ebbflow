# 站点截图

README 顶部使用两张截图：

| 文件 | 内容 |
| --- | --- |
| `docs/screenshot.png` | 全市场总览 |
| `docs/screenshot-cat.png` | 大类走势 |

更新截图：

```bash
npm start                      # 或 bin/start.sh

# 浏览器打开 http://127.0.0.1:5188 ，按 1440 宽截取
# macOS：Shift+Cmd+4 选区域，或 Shift+Cmd+5 截整个窗口
```

命名与放置：

- 总览页存为 `docs/screenshot.png`。
- 大类页存为 `docs/screenshot-cat.png`。
- PNG，宽度 1440 左右，`@2x` 亦可。

截图时避免带入 token、地址栏参数与浏览器书签栏。
