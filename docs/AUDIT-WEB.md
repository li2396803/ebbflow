## 一、结论

- **可用**：主流程（总览 → 分类 → 抽屉 → 搜索/自选/对比 → 导出）无阻断性坍塌，**5 条主要导航 0 pageerror、0 个 4xx、0 个请求失败**。
- **口径迁移基本干净**：全站数据区已无「份额 / 亿份」字样，CSV 无份额列，`?m=shares` 正确迁移并提示一次。
- **发现 1 个严重问题**：直达 `?sub=` 分享链接时，抽屉「区间表现」4 个 KPI 全部渲染成「—」，且数据就绪后不重绘（10s 后仍为 —）。
- **发现 4 个一般问题**：低覆盖端点回退在大类 KPI/表格不可见、成分 ETF 表两态口径差一天且注释与契约矛盾、自定义区间越界静默夹取、页脚残留过期「份额」文案。
- **清单里有 2 项功能不存在**：自定义区间的 UI 入口（只能改 URL）、导出 PNG。

## 二、方法与证据约定

每个用例都记录三件事：**做法**（怎么操作）→ **结果**（观察到什么）→ **证据**（截图 / 断言值）。
断言优先读应用自己的状态（`?debug` 会暴露 `window.__ebbflowState` / `window.__ebbflowApp`），避免只靠像素判断。
体积与耗时取自 `performance.getEntriesByType('resource')` 的 `transferSize`（线上压缩后大小）与 CDP `Network.emulateNetworkConditions` 节流。

## 四、问题清单

### 严重（1）

**F-1 直达 `?sub=` 分享链接时，抽屉「区间表现」KPI 全为「—」且永不重绘**

- **复现**：新标签直接打开 `?sub=中证2000&from=2022-06-01&to=2026-11-24`（或 `?sub=沪深300`），等 1.2s / 3s / 6s / 10s 观察。
- **现象**：`最新规模 —亿元 / 区间起点规模 —亿元 / 区间变化 — / 区间净申购（估算） 0.0亿元`，**10 秒后仍是 —**；而同页的成分 ETF 表（20/32 行）、注释、迷你图都正常。
- **对照**：同一小类从大类表点行进入 → `最新规模 103.0亿元 / 区间起点规模 34.7亿元 / 区间变化 +196.83% / 区间净申购 −10.4亿元`，全部正常。
- **成因**：`main.js:2697` 在启动 200ms 后调 `openDetail(state.sub)`，此时 `app.stats` 尚未算出，`detail.js` 的 KPI 段同步渲染成 `—`；之后 stats 就绪也没有再触发抽屉重绘（`openDetail` 只在 `chart` 事件里被重新调用，而该路径没覆盖 KPI 段）。
- **影响**：分享链接 / 书签 / 搜索直达是主入口，抽屉最显眼的 4 个数字失效；「净申购 0.0 亿元」比「—」更误导（会被读成「零申购」）。
- **建议**：`openDetail` 内等待 `app.stats`（或在 `stats` 就绪事件里对已打开的抽屉重跑一次 `openDetail(current)`）；KPI 缺失时显示 `—` 而非 `0.0`。

**证据**：`qa-b7-drawer-kpi-deep.png`（直达，全 —） vs `qa-b7-drawer-kpi-click.png`（点行进入，正常）

### 一般（4）

**G-1 低覆盖端点回退在大类 KPI / 大类表里不可见，导致「区间起点规模」是不同日期的混合和**

- `state.js:598` 计算了 `lowCoverage` 标志位，但**全仓没有任何渲染使用它**（`grep lowCoverage` 仅命中定义处这一行）。
- 实测 `cat=broad`、区间 2025-11-24 → 2026-11-24：11 个小类里 **2 个**期初被回退 —— `A股全指` 退到索引 1118、`中盘宽基` 退到 1192（即 2026-11 前后，实际窗口只剩约 21 个交易日），其余 9 个用 2025-11-24。
- 于是「区间起点规模 23,777.3 亿元」与「区间变化率 −32.33%」并非同一时点口径：严格同日口径应为 23,749.2 / **−32.25%**。表格里这两行也没有任何角标，排序时与其它行混在一起比较。
- 图表 tooltip 与抽屉注释都有「端点回退」说明，唯独大类侧没有。
- **建议**：在大类表对应行加「低覆盖」角标（`lowCoverage` 已算好），并在 KPI 的「区间起点规模」上加 tooltip 说明回退日期。

**G-2 成分 ETF 表：精确态注释写「不含期初当天」，实际含；与近似态差一天**

- `detail.js:531`（精确态）注释：「区间净申购（**不含期初当天**）」；但后端 `etfRanges` 实际**含**期初 —— 实测 `沪深300@1y`：Σ(32 只 ETF 精确 flow) = **−6173.6**，小类级含期初 = **−6174.0**（吻合），不含期初 = −6227.5（不吻合）。`docs/METRICS.md` 5.2 也明写「**包含期初当天**」。
- 近似态 `etf-range.js` 的 `flowSum` 用 `[i0+1 .. i1]`，是**真的不含**期初。
- 结果：同一列「区间净申购」在两种状态下口径相差一天，且注释文案在精确态是错的。
- **建议**：统一成契约口径（含期初），把精确态注释改成「含期初当天」，近似态同步改为含期初（或在两处都显式标注差异）。

**G-3 自定义区间越界 / 倒置被静默夹取，无任何提示**

- `from=2030-01-01&to=2030-12-31` → 实际 `2026-11-23 → 2026-11-24`；`from>to` → 单日；`from=2019-…` → 夹到 2021-11-22。
- 界面既无提示也无错误态，用户会以为看到的就是 2030 年的数据。
- **建议**：夹取后弹一次 toast（「已按可用区间 2021-11-22 ~ 2026-11-24 截断」），或在页头 chip 标出实际生效区间。

**G-4 页脚残留过期文案**

- overview 页脚：「全市场口径统计全部场内 ETF（含深市），不做债券 ×100 折算，**与细分行业页的「份额」口径不同**。」
- v4 起细分行业页已无「份额」，这句对比失去参照物，属于迁移遗漏。

### 建议（3）

**S-1 自定义区间没有 UI 入口**：`from`/`to` 只能手改 URL，`index.html` 里没有任何 `type="date"` 或区间选择器。检查清单第 4 项要求「自定义区间显示『近似』」，功能本身可用（见 A4），但普通用户到达不了。

**S-2 复访/离线的缓存策略在本地不可验证**
- **a.** `127.0.0.1` 默认不注册 SW（设计如此），必须 `?sw=1`；文档里最好写明，否则本地测「离线」会得到「SW 没注册」的错觉。
- **b.** 断网重载时控制台出现 2 条 `net::ERR_FAILED`（数据请求）；建议离线时把 data 请求的失败静默掉（或预缓存关键 JSON），让 console 保持干净。
- **c.** 无 SW 时复访仍整份重下 418 KB JSON（`http.server` 无缓存头）；上线环境请确认 CDN 的 `Cache-Control`。

**S-3 `#btnCatExport` 与 `#btnChartCsv` 绑同一个 handler**，导出文件字节完全一致（19,131 B）。两个入口做同一件事可以接受，但按钮文案一个写「导出 CSV」、一个图标无文字，建议明确区分（如页面级导出 = 全表、图表级导出 = 当前视野）。

### 未实现（清单要求但代码中不存在）

- **导出 PNG**（D13）：全站零命中，只有 CSV。
- **自定义区间的可视入口**（A3/B9 提到的「自定义」）。
