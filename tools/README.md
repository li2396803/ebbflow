# tools/ · 原始参考与校验基线

这个目录不是运行时依赖，只在**校验**和**维护分类体系**时用到。

| 文件 | 说明 |
| --- | --- |
| `original-index.html` | 原看板（B站 UP 主「生炸瓜」《ETF 细分行业资金流向》）的 HTML 快照，用作**结构/视觉回归**的比对基线 |
| `original-charts/*.js` | 原看板已发布的 10 个大类图表数据（86 个细分行业 × 1212 个交易日），用作**数值回归**的比对基线 |
| `parse-chunks.mjs` | 在 VM 沙箱里执行上述分片、取回数据对象（不联网、不执行页面脚本） |
| `gen-taxonomy.mjs` | 从原始数据生成 `lib/taxonomy.mjs`（86 个小类 → 成分 ETF / 配色 / 所属大类） |
| `probe-szse.mjs` | 深交所接口的一次性探测脚本（保留作排障用） |

## 为什么保留原作副本

1. **可验证**：`npm run verify:origin` 用自己抓的数据复算历史，与原看板已发布序列逐点比对（95,389 点，99.83% 完全一致；差异全部锁定在原看板冻结的 2 个交易日）。
2. **可重建**：分类体系（谁属于哪个细分行业）是从原作数据里提取的，删掉就断了来源。
3. **署名**：这些文件里包含原作者「生炸瓜」的署名痕迹，保留它是**对原作者的致谢与溯源**，不是水印 —— 站点渲染时不会出现。

> 这些文件**不会**被打包进 `site/`，也不参与任何页面渲染。若你再分发本项目，请保留本目录与 [`NOTICE.md`](../NOTICE.md)。
